AFazi Terapi 2.0 - TEMIZ PAKET

Bu paket Windows kullanıcısı için görünür klasörlerle hazırlanmıştır.

WEB_SURUMU       -> Web uygulaması ve açma bilgileri
GITHUB_KURULUMU  -> GitHub Pages ve APK Actions dosyaları
ANDROID_APK      -> APK üretme açıklaması
www/              -> Asıl web uygulaması
.github/          -> GitHub Actions'ın çalışması için GEREKLİ gizli/noktalı klasör

ÖNEMLİ:
.github klasörü Windows'ta gizli görünebilir. GitHub'a yüklerken mutlaka dahil edilmelidir.
GITHUB_KURULUMU klasöründeki dosyalar sadece kolaylık içindir; Actions'ın gerçek çalışması için .github/workflows/ altındaki dosyalar korunmalıdır.
